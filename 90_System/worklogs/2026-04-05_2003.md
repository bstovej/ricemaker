# Session Journal: 2026-04-05 20:03

## 🎯 Objective
Initialize and finalize the Ricemaker AI File Reviewer project, ensuring a modern dark-themed UI, robust local LLM (Ollama) integration, and reliable large-file processing via MapReduce chunking.

## ✅ Tasks Completed
- **UI/UX Design:** Created a responsive, dark-themed dashboard in `templates/index.html` and `static/js/main.js` with real-time polling and Markdown rendering.
- **Backend Infrastructure:** Developed `app.py` and `Dockerfile` to serve the Flask API and containerize the agent.
- **Agent Core Logic:** Optimized `agent.py` with:
    - Direct `requests` calls to Ollama to bypass `aisuite` connectivity issues.
    - Recursive chunking ("Map") for files exceeding token limits.
    - Global consolidation ("Reduce") to generate a `master_report.md`.
    - Persistent history tracking in `history.csv` to enable smart skipping of already-processed files.
- **Deployment Configuration:** Configured `docker-compose.yaml` with port 1688 and necessary volume mounts for persistence.
- **Troubleshooting:** Successfully resolved host-container networking issues and missing dependencies for PDF processing (`markitdown[all]`).

## 💡 Key Insights & Findings
- **Networking:** Ollama must be configured to listen on `0.0.0.0` (not just `127.0.0.1`) for Docker containers to connect via `host.docker.internal`.
- **Inference Optimization:** Using `keep_alive` and direct API calls is critical for performance when using large local models like `gemma4:26b` to avoid repeated VRAM loading.
- **MapReduce Strategy:** Splitting files at ~24,000 characters ensures that large PDFs don't overwhelm the LLM's context window while maintaining high review quality.
